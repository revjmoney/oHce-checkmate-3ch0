# Security Policy

## Reporting a vulnerability

Please report security problems privately here:
https://github.com/revjmoney/oHce-checkmate-3ch0/security/advisories/new

Do not open a public issue for a security problem. Say what you found, how to reproduce it, and which file or version is affected.

## What is in place

- Private vulnerability reporting
- Dependabot alerts and automatic security fixes
- Dependabot version updates (weekly) for GitHub Actions
- Secret scanning with push protection
- CodeQL code scanning (default setup)
- CI on every push and pull request: builds the project and runs a guard that fails on private data (home IPs, personal email, tokens, private keys)
